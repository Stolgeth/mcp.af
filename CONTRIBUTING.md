# Feedback and support

Bug reports, feature requests and independently written usage examples are welcome.
Include OS/CPU, Affinity version, desktop client version, package version and a
minimal reproduction. Remove private document content and credentials from diagnostics.

The original development sources are private. This public repository accepts
feedback and documentation reports; it is not a source-code contribution repository.
Original project materials are proprietary and free for personal and commercial
use under LICENSE. Third-party components retain their own licences and rights.
