# mcp.af artwork

The icon and SVG wordmark were supplied by the project maintainer for the mcp.af
1.0 launch. They identify this independent project.

The supplied files are preserved byte-for-byte in assets/. The PNG is used for
the plugin icon and logo; the SVG wordmark is used in the repository README.
